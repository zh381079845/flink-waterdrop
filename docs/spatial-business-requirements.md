# 空间业务需求清单（专家视角）

面向 Flink Waterdrop 类**流批一体 ETL / SQL 空间计算**场景，从真实行业与规划/国土/城建业务出发，列出可落地的空间业务需求。  
每条尽量写清：**业务目标 → 典型输入 → 核心空间能力 → 输出/验收**。

说明：

- **P0**：当前能力可直接或少量扩展支撑（WKT/谓词/缓冲/椭球面积距离/包络 JOIN/GeoJSON）
- **P1**：需补少量几何算子（交/并/差、长度、质心、简化等）
- **P2**：需索引、拓扑编辑、栅格、三维、网络分析或外部 GIS 服务
- 坐标默认假设：**WGS84 经纬度**；面积/距离优先**椭球/大地线**语义

## 18. 典型端到端业务链路（组合需求）

下列为可直接写成 Waterdrop 作业/验收用例的**组合故事**，每条对应多表 SQL。

### L-END-01 建设项目空间合规一条龙（P0）

1. GeoJSON/ JDBC 读入：项目红线、生态红线、基本农田、开发边界、文物控建带  
2. 包络预过滤 + `st_intersects` 做冲突检测  
3. `st_area` 算占用面积（平方米→公顷）  
4. `st_buffer(项目, 安全距)` 再与敏感点做 `st_dwithin`  
5. 输出：项目 ID、冲突类型、冲突图层、占用面积、是否一票否决  

### L-END-02 道路工程占地图斑分割统计（P0）

1. 道路中心线 `st_buffer` 得占地走廊  
2. 与地类图斑 envelope JOIN + 相交  
3. 按地类汇总走廊∩地类面积  
4. 输出占地平衡表  

### L-END-03 不动产宗地拓扑质检批处理（P0/P1）

1. 宗地自重叠：envelope + `overlaps`  
2. 房屋落宗：`st_within(房屋, 宗地)`  
3. 界址点：`st_dwithin(点, 边界, ε)` 或 `touches`  
4. 输出质检错误码与几何  

### C-END-01 城市事件实时落格派单（P0）

1. 事件点流 + 网格维表  
2. `st_within` 得网格编码  
3. 关联责任人属性下发  
4. 可选：`st_dwithin` 找最近摄像头  

### E-END-01 水源地突发污染溯源辅助（P0）

1. 报警点 `st_buffer` 分级圈  
2. 圈内排污口/企业名录（点落面）  
3. 上游河段简化：线与缓冲相交  
4. 输出可疑源清单  

### B-END-01 新店选址可行域（P0）

1. 剔除：基本农田/红线/竞品缓冲  
2. 保留：目标客群小区缓冲覆盖达标  
3. 输出可行栅格化前的候选面/点集（面可用差集 P1，点可用规则过滤 P0）  

### S-END-01 危化品事故影响快速评估（P0）

1. 事故点多层 `st_buffer`  
2. 与人口网格/学校医院相交  
3. `st_distance` 给出最近消防站  
4. 输出影响区 GeoJSON + 统计表  

### D-END-01 多源 GeoJSON 日更质检入库（P0）

1. `GeoJsonSource` 解析  
2. `st_geomfromwkt`/`st_area`/`st_envelope` 质检  
3. 与昨日库 `st_equals`/`面积差` 做变更集  
4. 合法入主表，非法入死信表
